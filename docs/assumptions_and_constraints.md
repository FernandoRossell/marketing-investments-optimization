# Supuestos y restricciones del proyecto

## Alcance
Este repositorio es un ejercicio de portafolio orientado a demostrar habilidades técnicas. No está diseñado como sistema productivo final.

## Licencias y herramientas
El proyecto se construye bajo el supuesto de **no disponer de licencias empresariales**. Se priorizan herramientas open source y ejecución local.

## Restricción crítica del dataset base
El dataset Store Item Demand Forecasting fue creado para forecasting de demanda y no contiene exposición a medios, spend, campañas ni treatment/control explícito.

## Implicación práctica
Para hacer MMM/uplift hay que añadir una capa de marketing:
- real/local, o
- sintética/documentada

## Testing y mantenibilidad
La mantenibilidad es parte explícita del proyecto. Por ello se incluyen pruebas unitarias, de integración y fixtures sintéticos.
